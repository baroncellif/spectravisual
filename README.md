# spectravisual

This repository contains a C-based application for interactive visualization of rotational spectra, specifically designed to overlay experimental spectra with predicted spectra generated by Pickett’s SPCAT (.cat files).

The program is conceptually similar to the AABS package available on PROSPE, but has been developed independently for personal use, with a focus on lightweight performance and custom interactive commands tailored to day-to-day spectroscopic analysis.

The application can be run:
	•	with both an experimental spectrum and a .cat prediction file, or
	•	with experimental data only, for pure visualization and inspection.

Controls and commands

### Window layout

The window is organised as a workbench: a command bar at the top (bar, measure,
sync, delete peak, offset, export, shortcuts), an icon rail on the left that
opens the tool panels, an inspector column on the right where the open panels
are stacked, and a single status line at the bottom with the cursor readout.
The two plots share one frequency axis, drawn under the prediction.

Every tool still has its keyboard shortcut, and the rail shows it on hover.

### Commands

The application is controlled via keyboard shortcuts and mouse interactions. Most commands act on both experimental and predicted spectra when Sync mode is active.

When Sync mode is not active, the same commands applied while holding Shift act only on the predicted spectrum.

View and navigation
	•	q / e : zoom out / zoom in (x-axis)
	•	a / s : move left / right along the frequency axis
	•	w / z : increase / decrease vertical scale of the experimental spectrum
	•	r : reset view

Cursor and measurements
	•	k / l : move cursor bar left / right
	•	g : measure distance (in MHz) between two selected points

Spectrum positioning
	•	Up / Down arrows : shift experimental spectrum up / down
	•	Tab : auto-fit experimental spectrum on the y-axis

Mouse interactions
	•	Right-click + drag (on experimental spectrum): zoom into a selected frequency region
	•	Left-click + drag (on a peak): measure experimental line frequency and copy it to the clipboard (PGOPHER-like behavior)

If a predicted line is selected while measuring a line frequency, an assignment is created automatically, similarly to PGOPHER.

Prediction handling
	•	Click on a predicted line: select a single transition
	•	Ctrl / Cmd + click: select multiple predicted lines
	•	m : apply Lorentzian broadening to predicted lines
	•	C : open a window to filter predicted transitions by intensity (log10(Int))
	•	T cat and T rot: the fields beside Offset rescale Pickett .cat line intensities between the catalog-generation temperature and a requested LTE rotational temperature (K). A .cat does not record its generation temperature, so both must be entered. The rescaling uses ELO and the DR rigid-rotor partition-function approximation; it changes relative predicted intensities, not the experimental trace's absolute scale.

Analysis tools
	•	f : select a frequency range to visualize
	•	N : open the list of assigned peaks (exportable)
	•	P : open peak-finding tool for the experimental spectrum (exportable)
	•	T : open rolling-average tool for experimental spectrum smoothing

Source files overview

main.c

Program entry point.
	•	Initializes the application
	•	Sets up the main loop
	•	Connects controller, view, and data loader

⸻

controller.c

Handles user interaction and input logic.
	•	Keyboard and mouse events
	•	High-level control flow
	•	Dispatches actions to the view or algorithms

⸻

view.c

Responsible for rendering and visual output.
	•	Draws spectra and graphical elements
	•	Manages coordinate transforms
	•	Handles zooming, panning, and overlays

⸻

layout.c

Manages screen layout and geometry.
	•	Defines plot regions and margins
	•	Handles resizing and viewport logic
	•	Ensures consistent placement of UI elements

⸻

loader.c

Handles data loading and parsing.
	•	Reads spectral data from files
	•	Parses input formats
	•	Prepares data structures for rendering

⸻

algorithms.c

Contains numerical and signal-processing routines.
	•	Peak handling or transformations
	•	Data filtering or analysis logic
	•	Utilities used by the controller or view

⸻

makefile

Defines compilation rules and dependencies.
	•	Compiler flags
	•	Source file list
	•	Build and clean targets
